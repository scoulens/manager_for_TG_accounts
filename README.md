A script for changing the nickname, username, and description for accounts in tg. First you need to enter here 
![image](https://github.com/user-attachments/assets/cf5d3b47-2709-445b-a9f9-2a1e94df5843)

Your API_ID and API_HASH can be obtained on the website https://my.telegram.org/apps
After that, in the database accounts.txt you also need to enter API_ID and API_HASH and data from Telegram accounts. 
![image](https://github.com/user-attachments/assets/4177b6cc-b203-4055-8c6b-eb6438456efa)
![image](https://github.com/user-attachments/assets/8c537e26-a80d-4579-86bf-9e08ddfc0f9c)

Besides accounts.txt there are 3 databases. Nicknames.txt bios.txt and base_usernames.txt
You can enter your data in them. It is IMPORTANT that each nickname / username / bio must be entered from a new line.The values are selected randomly from the presented options.If successful, you will see the following message
![image](https://github.com/user-attachments/assets/87ed8c34-3c76-4de5-a7c7-26b192ec8a8a)
